# ColdGuard Frontend

Capa de presentación de ColdGuard.

## Objetivo
Proveer dashboards operativos, gestión de incidentes, visualización de activos y flujos de atención.

## Alcance inicial
- Login.
- Dashboard de incidentes.
- Registro y consulta de unidades.
- Vista de detalle de incidente.
- Métricas operativas básicas.

## Relación con backend
Consume las APIs expuestas por `coldguard-platform`.
